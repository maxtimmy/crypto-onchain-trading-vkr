# Код приложения

В `vkr_data/` реализованы SQLite-хранилище, загрузка истории Binance с продолжением, проверки исходных ответов и сборка первой рыночной таблицы. `download.py` управляет запросами и контрольными точками, `store.py` — схемой хранения, `build.py` — признаками, ответом, разбиением и воспроизводимыми хешами.

Команды данных находятся в `scripts/market_data.py`; инструкция — в [описании пайплайна](../docs/data_pipeline.md). Загрузчик и сборка используют Python 3.9+ без сторонних зависимостей.

`vkr_model/` обучает два заданных варианта CatBoost, сохраняет модели и прогнозы, считает RMSE/MAE по всей выборке и кварталам, проверяет сохранённый запуск без повторного обучения. Команда — `scripts/train_model.py`, окружение Python 3.12.3 и зависимости зафиксированы в `uv.lock`; инструкция — в [описании обучения](../docs/model_training.md). Бэктест, стратегия и виртуальный счёт ещё не реализованы.

`diagnostics.py` содержит чистые расчёты парных ошибок, разложений, срезов и распределений фичей. `diagnose.py` проверяет происхождение входов, запрещает обучение и сохраняет новую локальную диагностику; `diagnostic_plots.py` строит графики только из её сводки. Команда — `scripts/diagnose_model.py`; [инструкция](../docs/model_diagnostics.md) описывает пороги, неопределённые показатели и повторяемость.

`controls.py` выполняет три фиксированных обучения только на внутреннем разбиении 2022 → 2023, очищает новую границу и проверяет сохранённые модели. `control_metrics.py` считает ошибки и парные сравнения без выбора победителя. Команда — `scripts/control_models.py`, [инструкция](../docs/model_controls.md). `attempts.py` ведёт совместимый со старыми записями общий учёт; произвольного общего предела запусков нет.

Расчёт фичей и торговые решения используются и в экспериментах, и в сервисе. Состояние счёта и обработанные интервалы сохраняются для восстановления после остановки. API и интерфейс добавляются после проверки торгового цикла.
