# Алгоритмическая торговля криптовалютой

Проект ВКР: торговая система с моделями машинного обучения, проверкой на истории и запуском в режиме бумажной торговли.

В исследовательской части сравним модели и наборы признаков, затем используем результаты в приложении. Источники выбираем по доступности и пользе для прогноза. Основной продукт — торговое ядро; диалоговый ассистент возможен после его готовности.

## Сейчас

Подготовлены план, задачи и структура репозитория. Сбор данных и разработка ещё не начались. Тему, параметры первой версии и календарные сроки предстоит согласовать с руководителем.

## С чего начинаем

Предлагаемая первая версия: BTC/USDT, спот без плеча, покупка, удержание или выход из позиции. Начальный горизонт прогноза — сутки. Частоту решений выберем после пробных выгрузок.

Сначала получим базовый бэктест на котировках, затем проверим дополнительные данные и модели. После выбора стратегии соберём сервис с риск-менеджментом, учётом портфеля и журналом сделок.

## Структура

Код будет в `src/`, настройки — в `configs/`, тесты — в `tests/`, исследовательские ноутбуки — в `notebooks/`. Данные и модели хранятся отдельно, без ключей и секретов в Git.

Инструкция запуска появится вместе с первой реализацией. Пока здесь находятся план и материалы для начала работы.
