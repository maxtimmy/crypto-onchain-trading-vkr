# Система алгоритмической торговли на рыночных и ончейн данных

Программная ВКР с исследовательской частью. Цель — построить торговое ядро, проверить вклад ончейн-признаков и запустить сервис бумажной торговли.

## Текущее состояние

Подготовлены план и структура проекта. Сбор данных, модельные эксперименты и реализация торгового ядра ещё не начинались. Параметры первой версии предлагаются для согласования с руководителем.

## Первая версия

Предлагаются BTC/USDT, спот без плеча, позиция в активе либо вне позиции и исходный горизонт прогноза сутки. Частота решений фиксируется после аудита доступности ончейн-данных. Обязательный результат — сквозной сервис бумажной торговли и воспроизводимый бэктест с издержками.

Ассистент, новости, второй актив и реальное исполнение — расширения после готового ядра.

## Организация работы

Текущие задачи ведутся в Issues. После рабочего цикла обновляются STATUS и журнал прогресса. Каждый эксперимент связывается с версией данных, конфигурацией и коммитом. Выводы и метрики добавляются только после фактических запусков.

Код размещается в `src/`, конфигурации — в `configs/`, тесты — в `tests/`, небольшие исследовательские ноутбуки — в `notebooks/`. Большие данные, артефакты моделей и секреты не включаются в Git.

Команд запуска торгового приложения пока нет: сейчас создан организационный каркас проекта. Требования к среде и воспроизводимый запуск будут добавлены вместе с первой реализацией.
