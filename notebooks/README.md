# Ноутбуки

[0001_source_quality.ipynb](0001_source_quality.ipynb) повторяет проверки сохранённых ответов Binance и Coin Metrics без сети: сверяет SHA-256 с манифестом и заново проверяет временные сетки и значения. Требуются локальные исходные ответы из каталога, указанного в `experiments/0001_source_probe_summary.json`; они не входят в Git. Открывать из корня проекта или `notebooks/`.

Дальше здесь будут разведочный анализ и исследовательские сравнения. Ноутбук указывает конфигурацию и версию датасета; результаты запуска оформляются в `experiments/`.

Общие функции переносятся в `src/`, чтобы расчёты совпадали с приложением. Финальный тест не открывается в ходе исследования. Перед коммитом удаляются лишние выводы и проверяется отсутствие секретов.
