# Тесты

Проверки загрузчика, сборки и пробных запросов запускаются без сети и дополнительных пакетов:

```bash
python3 -m unittest discover -s tests -v
```

В `test_source_probe.py` проверяются повторы вместе с пропущенной граничной точкой, полуоткрытые диапазоны, некорректные/неоконченные свечи, отсутствующая метрика при наличии строки, UTC и наносекундные метки Coin Metrics, отсчёт задержки от конца дня, сохранение свидетельств при таймауте/неполном HTTP-теле и повторное использование ответов с защитой от изменения файла.

`test_download.py` проверяет контрольные точки, остановку между записью raw и SQLite, отсутствие дублей, конфликты, границы пропусков, повторное использование снимка, таймауты, повреждённый gzip и ограничения 429/418. `test_build.py` проверяет формулы фичей и ответа, точные минуты, повреждённые окна, отсечение будущих часовых входов, границы частей, неизменность хешей и атомарность пересборки.

По мере реализации пайплайна добавляются проверки:

- Регулярного обновления источников и исторической доступности дополнительных признаков.
- Бэктеста: покупки, продажи, расходы, размер заявки и недостаток средств.
- Стратегии: риск-лимиты и одновременные сигналы при общем капитале.
- Сервиса: повторная обработка, недоступность источника, остановка между решением и записью сделки.

Отдельная проверка сопоставляет решения бэктеста и сервиса на одинаковых входах, модели и состоянии счёта.

Торговый пайплайн пока не реализован; перечисленные проверки бэктеста и сервиса ещё не выполнены.
