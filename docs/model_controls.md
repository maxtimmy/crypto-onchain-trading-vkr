# Контрольные обучения на 2022 → 2023

[Протокол 0005](../experiments/0005_catboost_controls.md) задаёт ровно три варианта CatBoost: опорный с 18 фичами и `l2_leaf_reg=3`, тот же с `l2_leaf_reg=30` и вариант без семи абсолютных объёмных фичей. Все модели имеют глубину 4 и 300 деревьев; другие параметры не меняются. Это ретроспективный исследовательский контроль двух гипотез, а не выбор итоговой стратегии.

## Запуск и проверка

Используются прежнее окружение Python 3.12.3, CatBoost 1.2.10 и локальная рыночная таблица. Новых зависимостей нет. Команды выполняются из корня проекта:

```bash
uv sync --locked
uv run --locked python scripts/control_models.py train --config configs/catboost_controls.json
uv run --locked python scripts/control_models.py verify --config configs/catboost_controls.json
```

**Повторный `train` создаёт три новых обучения.** Для проверки сохранённых файлов используется `verify`, который запрещает вызовы `fit`. По умолчанию проверяется последний успешно завершённый запуск; конкретный каталог выбирается через `--run-dir`.

Конфигурация закрепляет снимок и хеш таблицы, внутренние границы и единственные три разрешённых варианта. Опорная модель обучается заново, потому что модели 0003 уже видели ответы 2023 года. SQL читает только исходную часть `split=train`, без массивов валидации 2024 и финала 2025. Общая проверка целостности может технически хешировать весь снимок, не рассчитывая по нему модельных показателей.

## Временные границы и метрики

Внутреннее обучение — 2022 год, оценка — 2023. Строка относится к части по времени исполнения в UTC, а конец ответа должен быть строго раньше её конца. Поэтому дополнительно исключаются четыре ответа конца 2022, заходящие в 2023. Остаётся 8222 строки обучения и 8033 строки оценки. Список исключённых времён сохраняется в отчёте.

Постоянные прогнозы — ноль и одна средняя целевая доходность только 8222 обучающих строк. Она без пересчёта применяется к 2023 и всем кварталам. Все пять методов используют одинаковые строки каждой части. Показатели: RMSE/MAE в целом и по кварталам, среднее и стандартное отклонение ответов, прогнозов и остатков `prediction − target`; стандартное отклонение использует делитель `n`.

Для трёх моделей сохраняются парные превышения MSE/MAE над обоими постоянными прогнозами; для двух контролей — также над опорной моделью. Положительное превышение означает ухудшение, относительный процент считается после агрегации, при нулевом знаменателе возвращается `null`. Победитель автоматически не выбирается.

## Артефакты и учёт

Локальный каталог каждого нового запуска находится внутри `artifacts/training/0005_catboost_controls/`. Сохраняются три CBM, сжатый CSV с прогнозами пяти методов, параметры, метрики, конфигурация, версии окружения, исходники и манифест контрольных сумм. Старые файлы не перезаписываются. Исходный датасет сохраняет тот же физический и содержательный хеш.

Общий журнал `artifacts/training/attempts.jsonl` дополняется событиями `STARTED/SUCCESS/FAILED`; каждая из трёх моделей имеет свой `attempt_id`, хотя глубина одинакова. Два старых события начала обучения поддерживаются в прежнем формате. Неудачный запуск сохраняется и не повторяется автоматически. Общего лимита в 20 нет; три обучения этого этапа заданы протоколом, без расширения по полученному результату.

`verify` сверяет контрольные суммы, строки и ответы, списки 18/11 фичей, параметры и число деревьев. Загруженные модели должны воспроизвести прогнозы с абсолютным допуском `1e-12`; дробные метаданные CBM сравниваются с прежним узким допуском. Повторно рассчитываются метрики и базовое среднее, проверяется неизменность данных и журнала во время проверки. Более поздние корректные записи других запусков в журнале допускаются.

Гипотезы этого этапа сформулированы после просмотра 2024, а 2023 участвовал в прежнем обучении. Результат нельзя выдавать за новую независимую проверку или доказательство причинности. Ончейн, калибровка, бэктест и новая оценка 2024/2025 в этот этап не входят.
