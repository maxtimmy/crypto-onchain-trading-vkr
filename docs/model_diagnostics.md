# Диагностика сохранённых прогнозов

Этап 0004 разбирает ошибки двух CatBoost из запуска 0003 без переобучения. Проверяются разрешённые части: обучение 2022–2023 и валидация 2024. Финальный 2025 год не попадает в диагностические массивы, графики или метрики.

## Запуск

Нужны локальные данные и артефакты запуска 0003, описанные в [инструкции обучения](model_training.md). Используется то же окружение Python 3.12.3 и CatBoost 1.2.10:

```bash
uv sync --locked
uv run --locked python scripts/diagnose_model.py --config configs/catboost_diagnostics.json
```

Конфигурация привязана к конкретному каталогу обучения и точным SHA-256 его отчёта и манифеста. Диагностика проверяет исходные артефакты, версии, снимок и совпадение строк прогнозов с таблицей. Пропуски ключей, дубли, неверные ответы или подменённые файлы останавливают запуск; внутреннего соединения с молчаливым отбрасыванием строк нет.

Вызов `CatBoostRegressor.fit` на время диагностики принудительно запрещён. Данные открываются для чтения. Хеши моделей, прогнозов, базы и общего журнала попыток сравниваются до и после. Проверка целостности снимка может читать финальную часть технически; это не разрешает анализировать её распределения или прогнозы. Новых обучений, калибровки и торгового подбора эта команда не выполняет.

## Что считается

- RMSE, MAE, MSE и среднее/стандартное отклонение ответа, прогноза и остатка `prediction − target`. Стандартное отклонение — описательное, с делителем `n`, а не оценка неопределённости.
- Ошибки обучения и валидации в целом; для 2024 также месяцы и кварталы по времени исполнения в UTC.
- Парное превышение ошибок каждой модели над нулём и средним обучения: `mean(error_model² − error_baseline²)` и `mean(abs(error_model) − abs(error_baseline))`. Положительное значение означает ухудшение. Относительный процент — отношение агрегированного превышения к агрегированной ошибке базового метода.
- Разложение превышения MSE над постоянным `b`: `mean((prediction − b)²) − 2 × mean((target − b) × (prediction − b))`. Это арифметическое объяснение ошибки, не доказательство её причин.
- Режимы волатильности по `realized_volatility_24h`: границы — линейные квантили 1/3 и 2/3 только обучения. Группы: `x ≤ cut1`, `cut1 < x ≤ cut2`, `x > cut2`.
- Крупные движения: `abs(target)` выше линейного 95-го процентиля обучения. Это ретроспективный срез по будущему ответу, а не доступный в момент решения фильтр.
- Верхние 1% и 5% строк 2024 по `abs(target)`: количество округляется вверх, одинаковые значения упорядочиваются по времени исполнения. Набор строк общий для всех методов; сохраняется доля их суммарной квадратной ошибки.
- Для каждой из 18 фичей: минимум, максимум, медиана, межквартильный диапазон, процентили 1/99 и доля валидации строго вне диапазона обучения. Нормированный сдвиг медианы делится на межквартильный диапазон обучения.

Все квантили используют `method=linear`. Пустые группы сохраняются с `n=0` и неопределёнными метриками `null`. Нулевой знаменатель относительного показателя или нулевой межквартильный диапазон также дают `null`, а не бесконечность. Каждый срез содержит количество строк и долю своей части. Месячные превышения MSE/MAE проверяются взвешиванием по числу строк; месячные RMSE не усредняются.

## Артефакты и воспроизводимость

Каждый запуск создаёт новый локальный каталог внутри `artifacts/diagnostics/0004_catboost/`. В нём находятся полная `summary.json`, отчёт о происхождении и проверках, конфигурация, исходники с контрольными суммами, манифест и два PNG. Графики показывают помесячное превышение ошибок и эмпирические квантили прогнозов/ответов; увеличение центральных 1–99% обозначено отдельно и не меняет расчёт метрик.

Повторный запуск на тех же входах должен дать тот же содержательный хеш сводки. Времена запуска и служебный каталог не входят в содержательную сводку. Старые результаты не перезаписываются; неудача сохраняется в отчёте своего запуска. Бюджет обучений остаётся прежним.

В Git сохраняются код, настройки и краткая запись эксперимента с наблюдениями, ограничениями и гипотезами. Полная сводка, графики и исходные данные остаются локально вне Git. Перекрывающиеся четырёхчасовые ответы зависимы: статистические тесты для независимых строк и выводы о прибыльности здесь не применяются.
