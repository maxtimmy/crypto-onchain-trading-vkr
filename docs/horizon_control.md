# Парный контроль горизонта прогноза

Эксперимент 0007 проверяет один переход 4 → 24 часа на общих строках 2022/2023, с одинаковыми 18 фичами и настройками CatBoost. Полная постановка и ограничения — в [записи эксперимента](../experiments/0007_horizon_control.md), настройки — `configs/catboost_horizons.json`.

```sh
uv sync --locked
uv run --locked python scripts/compare_horizons.py train --config configs/catboost_horizons.json
uv run --locked python scripts/compare_horizons.py verify --config configs/catboost_horizons.json
```

Команда обучения выполняет два новых `fit`, отдельно для ответов на 4 и 24 часа. Повторный `train` означает новый экспериментальный запуск; для повторной проверки используйте `verify`. Для конкретного каталога можно добавить `--run-dir artifacts/training/0007_horizon_control/run-…`. Проверка запрещает обучение программно и загружает сохранённые модели. Неудачи записываются; автоматического повтора нет.

Загрузчик сверяет снимок, читает только исходный `split=train`, сохраняет прежние фичи и формирует оба ответа по точным минутным открытиям. Общий суточный допуск применяется до чтения цен, поэтому ни один новый ответ не использует 2024. Формула четырёхчасового ответа должна точно воспроизвести старую. Общие ключи, полные выбранные значения, границы и исключения получают отдельные хеши/счётчики. Исходная SQLite не изменяется.

Локальный каталог запуска содержит `h4.cbm`, `h24.cbm`, `predictions.csv.gz`, `metrics.json`, `params.json`, конфигурацию, версии, копии исходников, отчёт и манифест SHA-256. CSV хранит горизонт, метод, времена, часть, фактический ответ и прогноз. Для каждого горизонта три метода — ноль, среднее обучения и CatBoost; обе части имеют одинаковые ключи у всех методов.

Относительные превышения MSE/MAE сравниваются с собственными базовыми методами каждого горизонта. Сырые ошибки разных горизонтов не задают победителя. Квартальные веса проверяют общие агрегаты; зависимость перекрывающихся ответов описывается без утверждений о значимости. Технический контроль не оценивает торговую доходность и не открывает финальный 2025 год.
