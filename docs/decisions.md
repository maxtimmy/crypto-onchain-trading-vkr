# Решения и открытые вопросы

## Уже определились

- Основное направление — торговля: система сама формирует решения по позиции.
- Сначала строим торговое ядро, затем рассматриваем ассистента.
- Сравниваем доступные источники без заранее выбранного «главного».
- Показатели блокчейна входят в число кандидатов наряду с котировками, новостями и соцсетями.
- Репозиторий публичный, Google Документы открыты для просмотра по ссылке.

## Что предлагаем для первой версии

Тема — «Разработка системы алгоритмической торговли криптовалютой с использованием машинного обучения».

Начинаем с BTC/USDT и спота без плеча. Стартовое допущение — часовые свечи и прогноз на следующие сутки. Проверяем его на пробных выгрузках и фиксируем до сравнения моделей. Обязательный запуск — бумажная торговля; реальное исполнение и дополнительные функции оставляем на продолжение.

Последовательность: рыночные данные → простой бэктест → базовые модели → дополнительные признаки → итоговая стратегия → сервис и наблюдение. На следующем этапе используем проверенный результат предыдущего. Текст ВКР пишется параллельно.

Календарь на 16 недель — предварительная оценка. Его нужно привязать к срокам кафедры.

## Что уточнить с руководителем

Окончательную тему, параметры торговли, требования к результату и даты сдачи.

Новые решения записываем с датой и кратким основанием. 19 октября 2026 года пересмотрели акценты плана: исследование охватывает модели и сочетания данных, без привязки всей ВКР к одному источнику.
