# Решения и вопросы

## Зафиксировано в обсуждении проекта

- Основное направление — алгоритмическая торговля с самостоятельным формированием решений.
- Основная задача — сначала построить торговое ядро.
- Ончейн-данные входят в исследуемые источники.
- Диалоговый ассистент рассматривается поверх готового ядра.
- 19 октября 2026 года: по запросу автора репозиторий открыт публично, Google Документы доступны для просмотра по ссылке.

## Предложения для согласования

- Тема — разработка системы алгоритмической торговли криптовалютой на основе рыночных и ончейн-данных.
- Первая версия — BTC/USDT, спот, без плеча, позиция или отсутствие позиции.
- Исходный горизонт — сутки, частота решений после аудита данных.
- Обязательный режим — бумажная торговля, реальное исполнение как расширение.
- Ориентир календаря — 16 рабочих недель с последующей привязкой к дедлайнам.

## Открытые вопросы

Официальные сроки, актуальные требования кафедры, окончательная постановка и доступные источники данных.

Новые решения записываются с датой, основанием и ссылкой на соответствующую задачу.
