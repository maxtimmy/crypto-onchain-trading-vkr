# Первый технический бэктест

Фиксированные правила 0006 описаны в [протоколе эксперимента](../experiments/0006_technical_backtest.md), параметры — в `configs/btcusdt_backtest.json`. Это локальная симуляция с расходами по сценариям, без заявок на бирже и обучения. Используются исходные модели 0003 и только торговый период 2024; независимый финальный 2025 закрыт.

```sh
uv sync --locked
uv run --locked python scripts/backtest.py run --config configs/btcusdt_backtest.json
uv run --locked python scripts/backtest.py verify --config configs/btcusdt_backtest.json
```

Для проверки конкретного каталога добавьте `--run-dir artifacts/backtests/0006_btcusdt/run-…`. Команда `verify` сверяет артефакты и повторяет причинную сборку сигналов и симуляции без `fit`. Несовпадение хешей или ключей прекращает работу. Неудачные и незавершённые расчёты записываются с соответствующим статусом.

Расписание сигналов восстанавливается из завершённых часовых свечей с запасом 721 час. Оно не берётся из таблицы, где строки могли исчезнуть из-за будущего ответа. Минутная цена исполнения использует только открытие, без сведений об оставшейся части минуты. Для двух моделей проверяются 300 деревьев, список 18 фичей, параметры и совпадение с архивными прогнозами на общих ключах; допустимые отсутствующие прогнозы рассчитываются неизменными моделями.

Локальный каталог содержит сводку, полный отчёт, конфигурацию, версии и копии исходников, манифест SHA-256, 14 сжатых JSON с журналами сделок и часовыми/дневными кривыми, а также график капитала. Сводка детерминирована; время создания и пути не входят в содержательный хеш. Сохранность SQLite, исходного запуска и общего журнала обучений проверяется до/после. Значение `INCOMPLETE` сохраняет открытую позицию и предварительную оценку, но исключает итоговые финансовые метрики.

Числа комиссий, спреда, проскальзывания, шага количества и минимального номинала — явные предположения этого технического этапа. Для рабочего торгового сравнения нужны отдельные правила выбора и ограничения просадки; для ончейн-сравнения остаётся нерешённым вопрос прошлых версий и доступности метрик.
