# Описание данных

История пока не загружена. Для первого запуска бустинга готовим котировки и первые дополнительные фичи. Проверяем новости, соцсети и показатели блокчейна на небольших выгрузках, затем выбираем один–два доступных источника.

Выбранные дополнения подключаем уже на этапе 2, а не после первых моделей. На этапе 5 расширяем набор и проверяем вклад групп. Сохраняем покрытие, исходную частоту и время доступности. Таймфреймы и окна подготовки выносим в настройки; при разном покрытии пересчитываем сравнения на общем участке.

Для каждого выбранного набора нужно заполнить описание:

| Что записать | Какие сведения нужны |
|---|---|
| Источник | Название, ссылка, условия использования |
| Показатель | Смысл, единицы, идентификатор, актив |
| История | Начало и конец периода, частота |
| Время доступности | Публикация, задержки, возможные пересмотры |
| Качество | Пропуски, дубликаты, изменения методики |
| Обработка | Лаги, объединение источников, заполнение пропусков |
| Версия | Дата загрузки, параметры запроса, контрольная сумма или DVC-версия |

Кандидаты для первых запросов — Binance Public Data и Coin Metrics. Их пригодность ещё предстоит проверить. Исходные файлы храним вне Git; ключи и авторизационные ссылки в описание не добавляем.
