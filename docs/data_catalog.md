# Паспорт данных

Пробные выгрузки ещё не выполнены. Binance Public Data и Coin Metrics — кандидаты, а не подтверждённый состав датасета.

| Поле | Что зафиксировать |
|---|---|
| Источник | Название, точная ссылка, условия использования |
| Метрика | Идентификатор, определение, единицы, актив |
| Покрытие | Начало и конец истории, частота |
| Доступность | Окончание периода, публикация, задержка и пересмотры |
| Качество | Пропуски, дубликаты, изменения методики |
| Обработка | Лаги, агрегация, пропуски и синхронизация |
| Версия | Дата выгрузки, параметры, контрольная сумма или DVC-версия |

Исходные данные хранятся отдельно от Git. Не добавлять токены, ключи и авторизационные URL.
