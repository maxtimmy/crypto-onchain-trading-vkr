# Описание данных

История пока не загружена, источники не выбраны. Первые проверки — API рыночных данных и показателей сети. Начальный набор должен позволять обучить бустинг с ценами, объёмами и дополнительными фичами.

Историю и новые записи собираем своими загрузчиками. До выбора источника проверяем глубину доступной истории, детализацию, лимиты и условия использования. Исходная детализация должна позволять собрать свечи для намеченных сравнений.

Для каждого выбранного набора нужно заполнить описание:

| Что записать | Какие сведения нужны |
|---|---|
| Источник | Название, ссылка, условия использования |
| Показатель | Смысл, единицы, идентификатор, актив |
| Получение | API и метод, параметры запроса, пагинация, лимиты, точка продолжения |
| История | Покрытие по инструментам, частота, исходная детализация |
| Время | UTC; время события, публикации и получения, где они доступны |
| Доступность версии | Задержки, подтверждения, пересмотры и способ восстановления прошлого значения |
| Качество | Пропуски, дубликаты, изменения методики |
| Обработка | Расчёт из исходных записей или готовая метрика, агрегация, лаги, правила пропусков |
| Версия | Дата загрузки, версия набора и ссылка на внешнее хранилище |

Для метрик блокчейна отдельно указываем связь с активом и способ расчёта. Показатель сети нельзя без обоснования считать признаком любой торговой пары. Новости и соцсети рассматриваются после первых сравнений.

В бэктест попадает только версия значения, доступная на момент решения. Если это время не подтверждено, показатель исключается до проверки. Для редких обновлений сохраняем возраст последнего значения; правила заполнения пропусков описываем явно.

При сравнении источников используем общий доступный период. Исходные ответы и большие подготовленные файлы храним вне Git; ключи и авторизационные ссылки в каталог не добавляем.
