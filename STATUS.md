# Статус проекта

Обновлено 19 октября 2026 года.

Проверка источников для первого эксперимента выполнена. Есть скрипт пробных запросов, локальные исходные ответы, [каталог данных](docs/data_catalog.md), [паспорт эксперимента 0001](experiments/0001_btc_data_feasibility.md) и повторяемая проверка в ноутбуке. Готового датасета, обученных моделей, торговых результатов и сервиса пока нет.

## Что подтверждено

- BTCUSDT, спот без плеча; публичные API Binance и Coin Metrics доступны без ключа. Сохранены 63 основных ответа и два контрольных.
- Рынок за декабрь 2021 — декабрь 2025: 35 807 часовых свечей из 35 808 ожидаемых; пропущен час 24 марта 2023 года, две свечи имеют нестандартную длительность. Дневные свечи — 1492 из 1492.
- `TxCnt`, `AdrActCnt`, `AssetEODCompletionTime` — по 1492 дневных значения без пропусков и повторов; при соединении страниц нужна сортировка. Метрики объёма переводов вернули 403.
- В паспорте заданы целевая доходность, сценарный тайминг, пять сочетаний свечи/горизонта, начальные признаки, CatBoost и разбиение: обучение 2022–2023, валидация 2024, закрытый финал 2025.
- Десять проверок скрипта проходят; ноутбук повторяет проверки сохранённых ответов без сети.

## Ограничения

Дневная история Coin Metrics не подтверждает прошлые версии и время доступности каждого значения. Ончейн-вариант основного исторического бэктеста пока заблокирован. Задержки Binance моделируются сценарно; полная минутная история для исполнения и ответа ещё не загружена. Рыночный технический запуск не закрывает расширенный эксперимент.

## Ближайшие шаги

1. Написать минимальный загрузчик с продолжением после остановки; собрать минутные цены и версионированную часовую базу, изолировать выявленные дефекты и проверить все окна.
2. Подтвердить исторические версии ончейн-метрик либо выбрать источник/способ расчёта с такой возможностью.
3. Дополнить обзор литературы; до обучения зафиксировать окружение, а до торгового сравнения — расходы, правила торговли и численный критерий выбора.

Полная последовательность — в [плане](docs/plan.md). Календарные сроки пока не определены.
