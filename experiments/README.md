Дополнительно сохранены [пилот](0002_pilot_summary.json) и [проверка ончейн-источников](0002_onchain_sources.json). Повторная проверка таблицы — в `notebooks/0002_market_dataset.ipynb`.

[Сводка 0003](0003_catboost_summary.json) содержит версии, параметры, хеши и ошибки прогноза в целом и по кварталам. Модели и прогнозы находятся локально в `artifacts/training/`; повторная проверка выполняется [командой `verify`](../docs/model_training.md) без новых обучений. Общий журнал учитывает 2 из 20 сравнительных попыток; MLflow пока не подключён.
