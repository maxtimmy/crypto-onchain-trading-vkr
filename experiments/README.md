# Эксперименты

Запусков пока нет. Правила сравнения описаны в [протоколе](../docs/experiment_protocol.md). Для каждой попытки, включая неудачную, создаём запись по [шаблону](template.md).

Здесь будут ссылки на отчёты и сохранённые запуски. Конфигурация и версии кода и данных должны позволять повторить результат. Большие модели, прогнозы и датасеты размещаем во внешнем хранилище; MLflow подключается вместе с реализацией экспериментов.
