[Сводка 0001](0001_source_probe_summary.json) содержит покрытие, параметры текущего инструмента, результаты проверок и пути локальных свидетельств. Исходные ответы вне Git. Проверки можно повторить без сети в `notebooks/0001_source_quality.ipynb` при наличии локальных файлов.

[Сводка 0002](0002_market_dataset_summary.json) фиксирует входное покрытие, причины исключений, хеши и повторную сборку. Дополнительно сохранены [пилот](0002_pilot_summary.json) и [проверка ончейн-источников](0002_onchain_sources.json). Повторная проверка таблицы — в `notebooks/0002_market_dataset.ipynb`.

Правила сравнения описаны в [протоколе](../docs/experiment_protocol.md). Для каждой попытки, включая неудачную, создаём запись по [шаблону](template.md).

[Сводка 0003](0003_catboost_summary.json) содержит версии, параметры, хеши и ошибки прогноза в целом и по кварталам. Модели и прогнозы находятся локально в `artifacts/training/`; повторная проверка выполняется [командой `verify`](../docs/model_training.md) без новых обучений. Журнал сохраняет все начатые попытки без общего предела в 20; MLflow пока не подключён. Исторические ограничения в записях 0001–0004 сохранены в контексте прежней постановки.

[Сводка 0004](0004_catboost_diagnostics_summary.json) фиксирует происхождение диагностики, ключевые срезы и проверки повторяемости. Полные сводки и графики находятся локально в `artifacts/diagnostics/`; [команда диагностики](../docs/model_diagnostics.md) не расходует бюджет обучений и не открывает финальную оценку.

[Сводка 0005](0005_catboost_controls_summary.json) содержит разбиение, четыре исключения, метрики, параметры и хеши трёх контролей. Команда [проверки контролей](../docs/model_controls.md) воспроизводит сохранённый результат без обучения. В общем журнале пять начатых успешных обучений; универсального предела в 20 нет.
