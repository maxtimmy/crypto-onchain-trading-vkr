[Сводка 0001](0001_source_probe_summary.json) содержит покрытие, параметры текущего инструмента, результаты проверок и пути локальных свидетельств. Исходные ответы вне Git. Проверки можно повторить без сети в `notebooks/0001_source_quality.ipynb` при наличии локальных файлов.

Правила сравнения описаны в [протоколе](../docs/experiment_protocol.md). Для каждой попытки, включая неудачную, создаём запись по [шаблону](template.md).

Модельных запусков пока нет. Конфигурация и версии кода и данных должны позволять повторить результат. Большие модели, прогнозы и датасеты размещаем во внешнем хранилище; MLflow подключается вместе с реализацией экспериментов.
