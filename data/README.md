# Данные

Данных пока нет. Историю и новые записи будут получать собственные загрузчики через API. После пробных запросов здесь появятся инструкция запуска и схема хранения: исходные ответы, очищенные записи и таблицы признаков.

Источники, покрытие, задержки и версии описываются в [каталоге](../docs/data_catalog.md). Для каждого датасета сохраняются параметры сборки и ссылка на исходные записи. Большие файлы хранятся вне Git; секреты в данные и описание не добавляются.
