# Данные

В `probes/` находятся локальные исходные ответы первой проверки Binance и Coin Metrics. Каждый запуск содержит `raw/`, манифест URL/времени/хешей, сводку проверок и копию скрипта. Эти файлы исключены из Git; небольшая сводка для репозитория находится в `experiments/0001_source_probe_summary.json`.

```bash
python3 scripts/probe_sources.py --as-of 2026-10-19
```

Команду запускать из корня репозитория. Она создаёт новый каталог, не перезаписывая прежние ответы. Это ограниченная проверка источников; полная загрузка выполняется отдельно.

В `datasets/btcusdt_1h_4h_v1/` находится первая рыночная версия: `market.sqlite3`, исходные страницы в gzip, ссылки запросов, контрольные точки, отчёты и копии кода. В SQLite таблица `candles` хранит исходные значения и признаки качества, `dataset_rows` — 33 795 строк с 18 фичами и ответом, `dataset_exclusions` — 1269 исключённых решений. `datasets/btcusdt_pilot/` содержит короткую проверку восстановления.

```bash
python3 scripts/market_data.py download --config configs/btcusdt_1h_4h.json
python3 scripts/market_data.py build --config configs/btcusdt_1h_4h.json
```

Все базы и исходные ответы исключены из Git. Конфигурации и небольшая сводка `experiments/0002_market_dataset_summary.json` сохраняются в репозитории. Чтобы повторить точный снимок, нужны эти локальные данные; новый ответ API может содержать пересмотренную историю. Инструкция — в [описании пайплайна](../docs/data_pipeline.md).

Источники, покрытие, задержки и версии описываются в [каталоге](../docs/data_catalog.md). Для каждого датасета сохраняются параметры сборки и ссылка на исходные записи. Большие файлы хранятся вне Git; секреты в данные и описание не добавляются.
